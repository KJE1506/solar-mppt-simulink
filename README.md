# Solar MPPT System using MATLAB & Simulink

## Overview
Simulation and modelling of a Solar MPPT (Maximum Power Point Tracking) system using MATLAB & Simulink.

## Features
- PV system modeling
- MPPT implementation
- Power tracking response analysis
- Simulink monitoring dashboard

## Tools Used
- MATLAB
- Simulink

## Outputs
- P-V and I-V characteristics
- MPPT tracking response
- Real-time monitoring dashboard
